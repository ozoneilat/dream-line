# DREAM LINE — бесплатный лендинг

## Что уже есть
- Адаптивная страница для смартфонов.
- Логотип из предоставленного изображения.
- Плавающая кнопка ♿ с увеличением/уменьшением текста, высоким контрастом и выделением ссылок.
- Окно «Правила пользования».
- Текст и ссылки загружаются из `content/site.json`.

## Бесплатная публикация на Cloudflare Pages
1. Создайте аккаунт Cloudflare и аккаунт GitHub, если их ещё нет.
2. Создайте новый GitHub-репозиторий и загрузите в него содержимое этой папки.
3. В Cloudflare: Workers & Pages → Create → Pages → Connect to Git.
4. Выберите репозиторий. Для обычного статического сайта команда сборки не нужна; каталог сборки укажите `/` (корень репозитория), если интерфейс предлагает это поле.
5. После публикации получите адрес вида `имя.pages.dev`.

## Как менять текст
В первой версии тексты хранятся в `content/site.json`. Менять файл HTML не нужно, но для редактирования из браузера понадобится CMS. Рекомендуемый вариант — Pages CMS (pagescms.org), подключаемая к GitHub-репозиторию:
1. Откройте https://pagescms.org/ и войдите через GitHub.
2. Подключите репозиторий сайта.
3. Создайте конфигурацию `.pages.yml` в корне репозитория, чтобы `content/site.json` редактировался через визуальные поля. Схема CMS меняется со временем — следуйте актуальным инструкциям Pages CMS.
4. После сохранения изменений Cloudflare Pages автоматически пересоберёт/опубликует статические файлы.

Важно: сам Cloudflare не предоставляет встроенную визуальную админку для текста. Не храните пароли или приватные данные в файлах сайта.

## Перед публикацией
- Замените рекламный текст и ссылку кнопки в `content/site.json`.
- Добавьте актуальные правила пользования и контакты.
- Если добавляете видео, вставьте URL, разрешённый для встраивания (например, URL embed-плеера YouTube, а не обычную ссылку на просмотр).
- Проверьте иконку доступности и все элементы на телефоне.
- Виджет доступности помогает с отдельными настройками отображения, но сам по себе не гарантирует полное соответствие стандартам доступности.
